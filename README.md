# InstiForm App

Современная платформа для проведения онлайн-тестирования студентов

## Требования
* **Python**: версия **3.10**

---

## Шаги для локального запуска проекта

### 1. Получение исходного кода
Клонируйте репозиторий на свой компьютер и перейдите в папку проекта:
```bash
git clone https://github.com/XacDacZloyKot/insticform-app.git
cd insticform-app
```

### 2. Виртуальное окружение и зависимости
Создайте и активируйте виртуальное окружение, затем установите необходимые библиотеки:

```pycon
# Создание виртуального окружения
py -m venv venv

# Активация (Для Windows)
venv\Scripts\activate 

# Установка зависимостей
pip install -r requirements.txt
```

### 3. Запуск сервера
Запустите приложение с помощью Uvicorn:
```bash
uvicorn src.main:app --reload
```
